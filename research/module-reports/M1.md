## Formal Model Delivered

The protocol and executable reference semantics define:

1. capsule well-formedness;
2. evidence preservation;
3. eligibility before ranking;
4. P0 preservation;
5. mandatory dependency closure;
6. conflict visibility;
7. interface compatibility;
8. replacement correctness;
9. atomic activation;
10. safe rollback; and
11. the irreversible-side-effect boundary.

The frozen interfaces are retained. The executable representation uses frozen
dataclasses and `frozenset` values to realize the immutable tuple/set model.
Decision fingerprints bind task, capsule core, compiled view, validation, and
replacement reports. Validation recomputes content, evidence handles, closure,
conflicts, P0, and budget from capsule inputs instead of trusting compiler
flags.

The model is deliberately in-memory. Its hashes are M1 decision witnesses, not
a substitute for M2 signed integrity or M5 durable atomic pointer updates.

## TER, PIP, BSR, and Replacement Correctness

At run level:

- TER is passed required target-effect checks divided by required checks;
- PIP is passed protected-invariant checks divided by protected checks;
- BSR is triggered forbidden-spillover probes divided by forbidden probes.

All check sets must be non-empty. The activation gate requires `TER=1`,
`PIP=1`, and `BSR=0`, but experiments report all three components separately.
Evidence preservation, dependency closure, conflict absence, interface
compatibility, safe-boundary activation, task/report binding, prior-version
recovery, and irreversible-action controls are additional conjuncts. RCS is
secondary and cannot hide a failed component.

## Boundary from Five Neighbor Classes

| Neighbor | Distinction |
|---|---|
| Summary plus metadata | Does not by itself supply per-atom immutable evidence, closure, behavioral replacement, atomic activation, or rollback |
| Compression-only | Optimizes length/utility; ContractCapsule makes compression one policy inside a replacement protocol |
| RAG/retrieval-only | Selects passages; ContractCapsule gates eligibility, closes dependencies, exposes conflicts, preserves P0, and validates activation |
| Long-term memory | Persists/reuses facts; ContractCapsule substitutes immutable versions under an explicit behavior contract |
| Atom-only | Provides typed source-grounded commitments; ContractCapsule adds old/new interface and behavioral correctness, TER/PIP/BSR, binding, activation, and rollback |

Context Codec is the highest overlap risk because it already formalizes typed,
source-grounded commitments and verifiable compression. Therefore M1 excludes
atoms and compression from novelty and makes behavioral replacement the claim.
MCP, Skill, provenance, schema, package manifests, embeddings, and cache tiers
remain implementation/integration mechanisms, not standalone contributions.
